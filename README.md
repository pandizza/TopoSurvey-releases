# TopoSurvey — preuzimanje i update

Ovo je **distribucioni** repo za TopoSurvey (geodetski alati za AutoCAD / Civil 3D).
Sadrži samo instalacione fajlove i manifest za auto-update. Izvorni kôd je privatan.

## Instalacija

1. Otvori **[Releases](../../releases/latest)** i preuzmi `TopoSurvey-Setup-x.y.z.exe`.
2. Pokreni ga (instalacija je per-user, bez admin prava).
3. Pokreni AutoCAD / Civil 3D 2025 — TopoSurvey se učitava automatski (ribbon tab "TopoSurvey").

## Update

Plugin pri svakom pokretanju AutoCAD-a provjeri ima li novija verzija i, ako ima,
ponudi jednostavan update u jednom kliku. Ručno možeš uvijek preuzeti najnoviju
verziju sa [Releases](../../releases/latest) stranice.
